# AudiForm 2.2.0

> **⚠️ Highly experimental.** AudiForm 2 is still an early build. Expect
> bugs, rough edges and changes between builds. Keep backups of sessions
> you care about. **Please report any problem** at
> https://github.com/AudiFormer/AudiForm2/issues (or Help > Report a Problem
> in the app). Include the steps, and a session file or screenshot if you can.

A big update on top of [2.1.0](https://github.com/AudiFormer/AudiForm2/releases/tag/v2.1.0).

## Download

- `AudiForm2-2.2.0-windows-x64.exe`: a single portable program with ASIO
  support. No installer is needed. It keeps its settings in
  `%APPDATA%\Audiform2`. 2.1.0 offers this update by itself (Help > Check
  for Updates).
- `AudiForm2-2.2.0-windows-x64-wasapi.zip`: the same program without ASIO.
- `AudiForm2-2.2.0-macos-universal.zip`, `AudiForm2-2.2.0-linux-x64.flatpak`
  and `AudiForm2-2.2.0-linux-x64.tar.gz`: built on GitHub a few minutes
  after this release (see the 2.1.0 notes for how to open them). macOS and
  Linux builds are still lightly tested.

## New

- **Saving and closing**
  - **Closing with unsaved work** asks about each unsaved audio file and session in turn: Yes, Yes To All, No, No To All or Cancel. Unsaved audio files are now asked about too. Yes saves (through Save As when it needs a name), and the app closes once every save has finished.
  - **One Save As** in the File menu (Ctrl+Shift+S): the open file in the Waveform editor, the session in the Multitrack.
  - **Save As for sessions** is a new dialog: file name, location (recent folders and Browse), format (AudiForm session, or a copy as an Audition .sesx), sample rate, and whether markers go in.
  - Save As and Export each **remember their own format, settings and folder**, with a Location list of recent folders. A never-saved file starts in the format you last saved with.
  - **Save Selection As** (Ctrl+Alt+S) saves just the selected part as a new file, markers included.
  - **Ask before Save** (Settings > Autosave, off by default) asks before Save writes over the original audio file.
  - **The window** reopens where you left it, at its size, and maximized if it was.
  - **Quitting is quick**: with an ASIO driver it took about 5 seconds to let go; now under a second.
- **Waveform editor**
  - Double-click selects what's in view (Ctrl+A still takes the whole file).
  - Clicking a marker: a range marker selects its span; a plain one clears the selection. The view scrolls to it.
  - Shift+H / J / K / L nudge the selection's edges a pixel at a time (Edit > Adjust Selection).
  - Five clipboards: Ctrl+1 to Ctrl+5 pick which one Copy and Paste use (Edit > Set Current Clipboard).
  - Stop at End of Selection can be turned off (Shift+V).
  - Grabbing a selection edge with a quick pull no longer starts a new selection by mistake (also in the Multitrack).
  - Recording into a file: the view follows the take as it grows, so its waveform stays in sight.
- **Multitrack**
  - Nudge clips with Alt+, and Alt+. (Alt+Shift: five steps).
  - Swap Stereo Channels and Split Stereo to Center Mono on a track's right-click menu.
  - The metronome row stands out from the ruler in every theme.
  - MIDI clips are listed in the Files panel under the sessions; double-click one to open it in the Piano Roll.
- **Piano Roll**
  - **Play notes on the computer keyboard** once you've clicked in the Piano Roll: Z to / and ' are one octave, Q to ] the next, as in pattern sequencers. Page Down / Page Up change the octave. Notes still play while the instrument's settings window is open.
  - **A transport along the bottom**: time, Stop, Play, Pause, to the clip's start, Record, Loop this clip, the click, and the keyboard's octave and velocity.
  - **Record into the open clip** with its Record button or Shift+Space. **Overdub** adds to the notes there; **Replace** clears them from your first key on, as the playhead passes. One undo takes the whole take back.
  - **The clip's pitch**: − / + for octaves, Trans for semitones, Fine for cents. (A MIDI clip's Properties no longer has pitch.)
  - A ruler and a scroll and zoom bar along the top: drag the ruler to move the playhead, the wheel zooms, Shift+wheel scrolls, double-click the bar to see the whole clip.
  - Note ends are easier to grab for stretching.
  - Opening a file or session while the Piano Roll is in front brings the Editor forward.
- **Instruments**
  - New synth models, still being tuned (names will change): Atlantis Verse Lead, Wild Horses Demo Pad, Intro Lead and Crush Drone, and Ice Queen.
  - New synth controls: Analog, Bits / Downsample, Echo, LFO to Amp, Air, FM 2 and an envelope Curve.
  - Six "80s Synth" reverb presets.
  - A MIDI track's instrument heads its Effects rack, styled like the effect slots.
- **Themes**
  - **Wind** for a theme's backdrop picture: foliage that rustles in gusts (`"wind"` in a theme file).
  - Settings > Appearance > Visual effects: **Animate theme backgrounds** (off holds them still; splashes still play), the **theme animation frame rate** (15, 24, 30, 60 or the screen's) and **Play splash screens**.
  - Undercurrent has a new AUDIFORM logo in the menu bar and splash, rippling with the water. The splash runs at the screen's frame rate.
  - Layouts keep their proportions when the window grows.
- From the earlier 2.1.x work, also new here: the Favorites bar, a start-up view setting, the classic look for Grey Desktop '95, faster heavy sessions and Archive Session, Archive Session and session clips, the Video track and panel, OpenTimelineIO import, about 370 effect presets, the Waveform editor playing through the file's rack live, Linux AppImage and Flatpak packaging, and many fixes.

## Known issues

- **A MIDI clip's octave and Trans may not be heard on playback.** Fine works. The playback engine applies the shift in testing, but on at least one setup it isn't heard. Please report what instrument you use if you see this.
- A VST instrument's own window takes the computer keyboard's key presses, so they don't play the Piano Roll while it's in front (it runs as a separate program).

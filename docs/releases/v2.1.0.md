# AudiForm 2.1.0

> **⚠️ Highly experimental.** AudiForm 2 is still an early build. Expect
> bugs, rough edges and changes between builds. Keep backups of sessions
> you care about. **Please report any problem** at
> https://github.com/AudiFormer/AudiForm2/issues (or Help > Report a Problem
> in the app). Include the steps, and a session file or screenshot if you can.

A big update on top of [2.0.3](https://github.com/AudiFormer/AudiForm2/releases/tag/v2.0.3).

## Download

- `AudiForm2-2.1.0-windows-x64.exe`: a single portable program with ASIO
  support. No installer is needed. It keeps its settings in
  `%APPDATA%\Audiform2` (settings from the old `Audiform27` folder move
  there by themselves).
- `AudiForm2-2.1.0-macos-universal.zip`: "AudiForm 2.app" for Apple silicon
  and Intel Macs (macOS 11 or later). It isn't signed with an Apple
  developer certificate, so the first time, right-click the app and choose
  Open (or allow it in System Settings > Privacy & Security). macOS builds
  are new and untested: reports are very welcome.
- `AudiForm2-2.1.0-linux-x64.flatpak`: open it in your software centre, or
  run `flatpak install --user AudiForm2-2.1.0-linux-x64.flatpak`, then start
  AudiForm 2 from your app menu. It gets its runtime from Flathub, and keeps
  its own settings in `~/.var/app/io.github.audiformer.AudiForm2`. To
  update, open the next release's `.flatpak` the same way.
- `AudiForm2-2.1.0-linux-x64.tar.gz`: unpack and run `./audiform2`. It needs
  ALSA (`libasound2`), which almost every desktop distribution has. Still
  lightly tested.

The Linux and macOS programs are built on GitHub from `main` a few minutes
after this release, with one build fix that changes nothing on Windows.
The in-app updater installs new versions by itself only on Windows; on Linux
and macOS it opens the release page.

## Updates from inside the app

AudiForm 2 now checks for new versions by itself. A few seconds after it
starts, it looks at this project's latest release on GitHub. You can also
check any time from **Help > Check for Updates**.

When there's a newer version, a window shows its notes. On Windows,
**Update and Restart** downloads it, checks it against GitHub's checksum,
replaces the running program and starts the new one, asking about unsaved
work first. Only GitHub's release list is asked; nothing about you or your
work is sent. Turn the automatic check off in **Preferences > General**.

2.0.3 doesn't have the updater yet, so download this version by hand once.

## New

- **Recording**
  - Recording with no file open asks for the format first. New files start at 48 kHz, stereo, 24-bit, and 64 kHz is in the list.
  - **Shift+Space** in the Waveform editor records into the open file at the playhead.
  - A live waveform builds while you record.
  - Long takes save in the background, so stopping is instant.
- **Input monitoring:** a button on armed audio tracks plays the live input through the track's effects, fader and pan. Takes stay dry. If it starts to howl, monitoring turns itself off.
- **Surround files** in the Waveform editor
  - A transport button picks how they play: stereo fold-down, headphones (binaural), bookshelf speakers (crosstalk cancelled), or each channel to its own output.
  - The Levels panel shows every channel before the fold.
- **MIDI and the Piano Roll**
  - Resizable velocity lane, velocity bars inside notes, and a channel picker in the notes' colours (multi-part instruments play each channel with its own sound).
  - FL-style velocity mapping for your keyboard (Preferences > Multitrack > MIDI).
  - Copy, paste and duplicate notes with the usual keys. Dragging one picked note moves all of them.
  - The mouse wheel over the keys zooms, and there's a stretch bar on the right.
  - Velocity lanes on MIDI clips in the Multitrack editor.
- **Multitrack**
  - A pre-render button on every track header.
  - Resizable track headers.
  - Copy, paste, duplicate, Alt-drag and group moves for audio and MIDI clips.
  - Mixdown exports open when they finish.
- **Plug-ins**
  - VSTs open straight into their own window. Power and presets are on the slot's right-click menu.
  - The plug-in menu is grouped and no longer runs off the screen.
  - Automation lanes for VST controls, on tracks and on clips.
  - The Windows network prompt now comes at most once, not once per build.
  - Fixed: effects that didn't load until you added another, instruments that stayed silent from a MIDI keyboard, and typing values into plug-in windows.
- **Effects**
  - Your Audiform 1 effect set is back, with duplicates removed.
  - Reverb's first type is Studio Reverb.
  - Stereo Width has two centre-notched sliders.
  - Amp Model is now a full rig: boost, cabinets, two mics with pan, room and doubler.
- **Look and layout**
  - Mute, Solo, Arm, Mono and polarity buttons show symbols instead of letters.
  - Music is now the start-up workspace, with the Piano Roll beside the Editor and Mixer. The old Default is gone.
  - Studio Lite gets a boot splash.
  - Windows' light mode no longer turns dark themes white.
  - The file tabs strip is gone.
- **Files panel:** Delete closes the picked files, asking about unsaved edits first.

# AudiForm 2.0.3

> **⚠️ Highly experimental.** AudiForm 2 is still an early build. Expect
> bugs, rough edges and changes between builds. Keep backups of sessions
> you care about. **Please report any problem** at
> https://github.com/nwh212/AudiForm2/issues (or Help > Report a Problem
> in the app). Include the steps, and a session file or screenshot if you can.

A small fix release on top of [2.0.2](https://github.com/nwh212/AudiForm2/releases/tag/v2.0.2), for our first Linux bug.

## Download

- `AudiForm2-2.0.3-windows-x64.exe`: a single portable program with ASIO
  support. No installer is needed. It keeps its settings in
  `%APPDATA%\Audiform27`.

## Fixed

- **Effects rack on Linux:** each slot's menu button showed as a square, and the squares drifted further right row by row. Two causes:
  - The arrow was a text character that the system's fonts didn't have. It is now drawn.
  - The button outgrew its cell and widened the next row. Every row now has one fixed width.
- **Missing symbols on Linux and macOS:** AudiForm now falls back to the system's symbol fonts (DejaVu Sans, Noto Sans Symbols 2 or Apple Symbols), so arrows and other symbols no longer show as boxes. Fedora's Japanese font is also found now. Windows is unchanged.

## Building on Linux

Install the ALSA headers first, then build as usual:

- Fedora: `sudo dnf install alsa-lib-devel`
- Debian/Ubuntu: `sudo apt install libasound2-dev`

```
cargo build --release -p audiform2
```

Linux builds are still lightly tested. Reports are very welcome.
